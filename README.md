# Follie Moda Giovane — sito demo

Demo statica (un solo file HTML, nessuna build necessaria) pensata come proposta per Follie Moda Giovane, Via Fratelli Rosselli 6, Cesano Boscone (MI).

## Come pubblicarla su GitHub Pages

1. Crea un nuovo repository su GitHub (es. `follie-moda-giovane`).
2. Carica `index.html` nella root del repository.
3. Vai in **Settings → Pages**, imposta come sorgente il branch `main` (cartella `/root`).
4. Dopo un paio di minuti il sito sarà visibile su `https://<tuo-utente>.github.io/follie-moda-giovane/`.

Nessuna dipendenza da installare: è HTML/CSS/JS puro, funziona anche aprendo `index.html` direttamente nel browser.

## Contenuti da verificare con il negozio prima di rendere il sito definitivo

Alcuni dati non erano disponibili pubblicamente e andrebbero confermati:

- **Orari di apertura** — al momento il sito rimanda a "chiamaci per gli orari".
- **Link Facebook** — punta a `facebook.com/folliemodagiovane`, da verificare che sia l'URL corretto della pagina.
- **Indirizzo email**, se vogliono riceverne una tramite sito.
- **Foto reali** del negozio e dei capi — la demo usa illustrazioni astratte al posto di foto prodotto, che andrebbero sostituite con scatti reali.

## Stack

HTML/CSS/JS vanilla, font da Google Fonts (Bebas Neue, Space Grotesk, IBM Plex Mono), mappa incorporata da OpenStreetMap. Nessun framework, nessuna dipendenza a pagamento.
